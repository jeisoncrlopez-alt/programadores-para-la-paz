Al enviar una petición POST a http://localhost:3000/registro con el JSON propuesto, el servidor Express procesa el cuerpo de la solicitud gracias al middleware express.json(). 

Luego, extrae las propiedades 'nombre' y 'mensaje' desde 'req.body' y responde con un código de estado 200 OK, devolviendo un objeto JSON que confirma la recepción.

Respuesta exacta recibida:
{
  "estado": "Datos recibidos",
  "nombre": "Maria",
  "mensaje": "Hola comunidad"
}
